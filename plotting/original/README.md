# Plotting routines

These modules provide the panel functions and vector-layout steps used by the figure entry points. Run figures through `run.py` from the repository root, or select one plotting target with `python plotting/render_original.py 2`.

Numerical inputs are read from `data/processed/`. Temporary figure components are written to the ignored `.render_workspace/` directory; completed figures are saved to `outputs/figures/`. Selected photographic illustrations are read only from the separately configured local asset directory.
